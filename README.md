# Morse code Research
Morse code is a method of communication that uses a series of dot (.) and dashes (-) to represent letters, numbers, and symbols. It was mainly used in telecommunication systems such as telegraphs and radio communication.Each letter and number has its own unique morse code pattern.Example:
- A = .-
- B = -...
- C = -.-.
- 1 = .----
- 2 = ..---

  Morse code allows massages to be sent over long distances using sound, light, or electrical signals.

  ## History of Morse code
  Morse code was developed in the 1830s and 1840s by samuel Morse and Alfred Vali. It was created to improve communication through the electric telegraph system.
  ## How Morse code works
  - Dot (.) = short signal
  - Dash (-) = long signal
